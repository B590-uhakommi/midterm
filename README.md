##TITLE : Notes APP

##DESCRIPTION :
The Notes app allows users to create notes as needed and delete them when they are no longer important.

##FUNCTIONALITY :
The following required functionalities have been implemented:

--> Users log into the app using their credentials.
--> Users navigate to the notes page, click "Add Notes," and are redirected to the note creation page.
--> Users can input a title and description, save the note, and return to the notes page.
--> Users can edit the title or task by selecting it, and after updating, the changes are reflected in the same entry.
--> Users can remove tasks by clicking the "X" icon, which prompts a confirmation before deletion.
--> Users can log out using the logout button.

##EXTENSIONS :

--> The enableEdgeToEdge() function is used to enable a full-screen immersive layout that hides the status bar for a seamless experience.
--> Extensions in the code include libs.plugins.android.application for the Android application plugin and libs.plugins.kotlin.android for Kotlin integration in Android development.
